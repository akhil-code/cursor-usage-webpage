Privacy Policy

This page explains how the Cursor Usage Tracker Chrome extension handles data. The extension is built for transparency: it runs on your device, shows usage from your existing cursor.com session, and does not sell, share, or warehouse your information with third parties.

EffectiveMay 3, 2026
Overview

What this extension does

Cursor Usage Tracker is a Chrome extension that reads your Cursor account usage data directly from cursor.com and displays it in the extension popup. It shows statistics such as your included limit consumption, billing cycle reset date, and on-demand usage - all fetched on your device using your existing Cursor session.

No data is collected, stored on external servers, or shared with anyone. Everything stays between your browser and Cursor's own website.

Data collection

Information we do not collect

The extension does not collect, store, transmit, or share any of the following:

  • Personal information (name, email address, account credentials)
  • Browsing history or activity on any website
  • Cursor session tokens, cookies, or authentication data
  • Usage statistics or metrics from your Cursor account (beyond displaying them temporarily in the popup)
  • Keystrokes, clipboard contents, or any user input
  • Device identifiers or fingerprinting data
  • Location data of any kind
Permissions

Chrome permissions used and why

The extension requests the minimum permissions required to function. Here is what each permission is used for:

  • cookies

    Used to detect whether you are signed in to your Cursor account. The extension reads the presence of the Cursor session cookie on cursor.com to determine login state. Cookie values are never read, stored, or transmitted.

  • tabs

    Used to open the Cursor sign-in page in a new tab when you click "Sign in" in the popup. No tab content, URLs, or browsing history is accessed or read.

  • https://cursor.com/*
    https://www.cursor.com/*

    The extension fetches your usage data directly from Cursor's own API endpoints on cursor.com. This is the same data you would see if you visited your account dashboard. Requests are made on your behalf using your existing browser session and go directly from your browser to Cursor's servers - they do not pass through any third-party infrastructure.

Data use

How data is used

Usage data fetched from Cursor's API is used solely to render the statistics displayed in the extension popup (total usage percentage, requests used, billing reset date, and on-demand spend). This data is held in memory only for the lifetime of the popup and is discarded when the popup is closed.

The extension does not persist any data to chrome.storage, localStorage, IndexedDB, or any other storage mechanism.

This website has no user accounts. The only information it receives is what you choose to send through the feedback form on the Support page: a description of the issue and, optionally, an email address so we can reply. It is used only to respond to and act on your feedback.

Security

Data storage & security

No user data is stored by this extension at any time. Because all processing happens locally in your browser and all network requests go directly to cursor.com (which is already trusted by your browser session), there is no additional data storage surface introduced by this extension beyond what your normal Cursor session already entails.

There are no remote code execution mechanisms, no analytics SDKs, and no background scripts that run while the popup is closed.

Third parties

Third-party services

This extension does not integrate with, send data to, or rely on any third-party analytics, advertising, tracking, or data-broker services. The only external network contact made by the extension is to cursor.com to retrieve your own usage data.

The Inter typeface used in the popup UI is loaded from Google Fonts (fonts.googleapis.com) when the popup is opened. This is a standard font request and does not include any user-specific information beyond what is present in a normal browser HTTP request (for example, IP address and user-agent). If you prefer, you may modify the extension to use a locally bundled font.

Eligibility

Children's privacy

This extension is intended for users who have a Cursor account and are subject to Cursor's own terms of service. It is not directed at children under the age of 13. Because the extension collects no personal data, there is no special handling required under COPPA or similar regulations beyond Cursor's own policies.

Updates

Changes to this policy

If this privacy policy is updated, the effective date at the top of this page will be revised. Any material changes that affect data handling will also be noted in the extension's Chrome Web Store listing changelog.

Continued use of the extension after an update to this policy constitutes acceptance of the revised terms.

Contact

Questions or concerns

If you have questions about this privacy policy or how the Cursor Usage Tracker extension handles data, email solocoderdev@gmail.com or use the support link on the Chrome Web Store listing.
