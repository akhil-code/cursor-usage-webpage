How it works

FAQ

Frequently asked questions

Everything you might want to know about installing and using Cursor Usage Tracker.

Is the Cursor Usage Tracker extension free?

Yes. Cursor Usage Tracker is completely free. There are no paid tiers, ads, in-app purchases, or upsells. Install it from the Chrome Web Store and use every feature with no limits.

Does the extension store or transmit my Cursor data?

The toolbar popup fetches usage from cursor.com using your existing browser session and keeps it in memory. Nothing is sent to our servers.

Do I need a separate login?

No. The extension uses your existing Cursor session, and there is no account on this site.

Which Cursor plans does it support?

Cursor Usage Tracker works with all Cursor plans, including Free, Pro, and Business. Your membership type is shown as a badge in the popup, and the appropriate breakdowns (Auto/Composer, API/frontier, on-demand) appear based on your plan.

Will it slow down my browser?

No. The extension is lightweight (around 211 KiB) with no background scripts and no remote code. It only fetches usage data when you open the toolbar popup, so it has no measurable impact on browser performance.

Where can I report bugs or request features?

Email solocoderdev@gmail.com or use the support link on the Chrome Web Store listing. Feature requests and bug reports are very welcome.
